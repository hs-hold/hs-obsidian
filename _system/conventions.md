# Memory and task conventions

[verified] Written 2026-11-23 during the approved agent-system upgrade. These conventions apply to the shared vault. They do not replace [[00 Profile]] or bot rule files.

## Fact tags
When writing a fact, mark its kind in the line or a short prefix:

- `[verified]` — checked against a primary source this turn (page, inbox, file, code, or a dated owner message).
- `[reported]` — someone reported it (a bot, a broker, a partner) and it has not been independently checked.
- `[hypothesis]` — an inference, not a measured fact.
- `[decision]` — an owner decision. Copy it also into [[Decisions Log]] the same day.

Do not present a hypothesis or a report as a verified fact.

## Stale marking
Do not delete historical items to "clean up." If something is no longer true or is finished:

1. Leave the original line in place.
2. Mark it `[stale]` with the date and a one-line reason, or move the live status to [[Open Items]] and point back to the source.
3. Closed work goes to the History section of [[Open Items]], with the evidence link. Never close an item without verification.

## Canonical sources
See [[Canonical Sources]] for where each type of information lives. If two files disagree, the source listed there wins, and the other file should be updated or marked stale — not silently overwritten.

## Decisions
Append only to [[Decisions Log]]. Never rewrite or delete an older entry. If a later decision changes an earlier one, add a new dated entry that says so and point at the old id.

## Sync must not overwrite newer decisions
- `safe-push.sh` already runs `git pull --rebase --autostash` before commit and push. Keep that order.
- Write new decisions to [[Decisions Log]] and the daily note **before** rebuilding `00 Memory.md`.
- Never edit `00 Memory.md` by hand; it is generated by `_system/scripts/build_memory_file.py`.
- If a rebase or merge conflict appears, keep the newer dated decision and do not drop Open Items or Decisions Log entries.
- Twice-daily harvest remains 13:00 and 23:00 as the running routines. The original owner request (17 Nov) said 23:30; that contradiction is an open item for the owner (see [[Open Items]] OI-M10). Do not "fix" the time in docs or in the routine until the owner decides.

## Tasks
[[Open Items]] is the single tracker for open decisions and tasks. Existing project lists may remain as history, and should point here.
