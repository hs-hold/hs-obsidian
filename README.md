# H.S HOLDINGS — Vault

כספת משותפת לכל הבוטים ולשותפים (דביר, טל, ערן).

## מבנה
- `00 Inbox` — פתקים מהירים שעוד לא סודרו
- `Notes` — פתקים ודברים לזכור של הבעלים
- `Deals` — עסקה = פתק אחד (`כתובת.md`)
- `Markets/Indianapolis`, `Markets/Atlanta` — מחקר שוק, מיקודים, אזורים
- `Contacts` — אנשי קשר מקומיים (מתווכים, קבלנים, הולסיילרים, מלווים)
- `Meetings` — סיכומי פגישות ושיחות
- `Agents/<שם הבוט>.md` — יומן עבודה של כל בוט

## כללים לבוטים
- כל פתק בקובץ Markdown, שם קובץ ברור, תאריך בפורמט YYYY-MM-DD.
- להוסיף, לא למחוק תוכן של אחרים. עדכון = הוספת שורה מתוארכת.
- לא לשמור סיסמאות, טוקנים או מספרי כרטיסים.
- `git pull --rebase` לפני כתיבה, `git push` אחרי.
